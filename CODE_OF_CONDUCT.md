# Code of conduct

OpenDiag adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and patient (many users are not mechanics or
developers), assume good faith, give credit, and keep discussions about the
work. Harassment, personal attacks and sharing others' personal data (including
VINs or number plates) are not accepted.

Report problems to the maintainers privately through the repository owner's
GitHub profile contact. Maintainers will review every report and keep the
reporter's identity confidential.
