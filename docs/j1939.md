# Trucks, buses and machines: SAE J1939

Most heavy trucks, buses and many machines (tractors, construction equipment,
generators, boats with diesel engines) talk **SAE J1939**: a CAN network at
250 kbit/s with 29-bit identifiers. Generic OBD-II scan tools often see nothing
on them. OpenDiag reads J1939 **read only** on the **Trucks (J1939)** page.

Status: **Implemented but not hardware-verified.** It is tested against a
simulated J1939 network (`crates/opendiag-sim/src/j1939.rs`) and against the
examples printed in the ELM327 datasheet. No real truck has been tested yet.

## What you need

- An **ELM327 v1.4b or newer** (or an STN / OBDLink) adapter. Many cheap
  clones claim to support protocol A (J1939) but behave differently; OpenDiag
  says so if the adapter refuses it.
- The right cable. North American trucks and many machines: **9-pin round
  Deutsch** (SAE J1939-13; black = 250 kbit/s, green = 250 or 500 kbit/s) to a
  16-pin socket for the adapter. Many European trucks: the 16-pin socket
  (Type B, 24 V) or a manufacturer plug. See **Find my connector**.
- **24 V vehicles:** check the adapter is rated for 24 V. A 12 V-only adapter
  can be destroyed.

## How to use it

1. Connect to the adapter as usual (Connect). On a truck, the OBD-II step often
   says the vehicle did not answer: that is expected. Press **Try J1939**.
2. Ignition on. Press **Read the vehicle**. It takes about 15 seconds, because
   most J1939 values are only *heard*: the control units send them about once a
   second without being asked.
3. You see each control unit (by its J1939 address), its warning lamps, its
   **active** fault codes (DM1) and **previous** codes (DM2), engine values,
   engine hours, distance and the VIN when the vehicle reports them.
4. To read a car again, reconnect (the adapter stays in J1939 mode otherwise).

## Reading a J1939 fault code

A J1939 code is two numbers, not a P-code:

- **SPN** (suspect parameter number): *what* is affected, e.g. SPN 110 is
  engine coolant temperature. OpenDiag names only the few SPNs in its parameter
  list; for others, look the SPN up in the manufacturer's manual.
- **FMI** (failure mode identifier): *how* it failed, e.g. FMI 4 = voltage
  below normal or shorted to low. All FMIs are explained in plain words.
- "Seen N times" is the occurrence count the control unit keeps.
- If a unit says it uses an *older code layout* (the conversion-method bit),
  the SPN may be misread: OpenDiag says so next to the code.

## What OpenDiag sends

Almost nothing. It listens (`AT MP`) for DM1 and the broadcast values. It
sends a request (PGN 59904) only for the groups on the safety policy's list
(`opendiag_safety::J1939_REQUESTABLE`): DM1, DM2, VIN, engine hours and
vehicle distance. Clearing codes (DM3, DM11) and every other request are
refused by the safety layer and are not offered.

## Values read

| Value | SPN | PGN | How |
| --- | --- | --- | --- |
| Engine speed | 190 | 61444 (EEC1) | heard |
| Engine coolant temperature | 110 | 65262 (ET1) | heard |
| Engine oil pressure | 100 | 65263 (EFL/P1) | heard |
| Wheel-based vehicle speed | 84 | 65265 (CCVS) | heard |
| Engine fuel rate | 183 | 65266 (LFE) | heard |
| Ambient air temperature | 171 | 65269 (AMB) | heard |
| Battery potential | 168 | 65271 (VEP1) | heard |
| Fuel level 1 | 96 | 65276 (DD) | heard |
| Total engine hours | 247 | 65253 (HOURS) | requested |
| Total vehicle distance | 245 | 65248 (VD) | requested |
| VIN | 237 | 65260 (VI) | requested |

Values the vehicle marks as "not available" or "error" are shown as such,
never as a number.

## Sources

- ELM327 datasheet (ELM327DSL), sections "SAE J1939 Messages" and "Using
  J1939": protocol A, `AT MP`, PGN requests with automatic byte reversal,
  header formats (`AT JHF0/1`), negative acknowledgements and multi-segment
  answers. The parser tests use the datasheet's own example lines.
- SAE J1939-21 (identifiers, transport protocol), J1939-71 (parameter groups
  and scaling) and J1939-73 (DM1/DM2 layout, lamps, FMIs). The parameters
  above are also published in the open FMS Standard (fms-standard.com).

## Known limits (honest list)

- 250 kbit/s only (protocol A). 500 kbit/s networks need protocol B setup.
- How an ELM327 prints a *broadcast* multi-segment DM1 (many codes at once)
  while monitoring is not shown in the datasheet; OpenDiag accepts it with or
  without the byte-count line. To be confirmed on a real vehicle.
- No address claim (J1939-81): the ELM327 uses the fixed tool address F9.
- SPN names for codes cover only the parameters above.
- Raw CAN interfaces (SocketCAN, J2534) are not supported yet.

## Testing on a real vehicle

Connect, run the Trucks (J1939) page, then compare the codes with the
dashboard lamps or another tool. Results are recorded per operating system as
"j1939_read_codes" and "j1939_live_data". Please send a compatibility report
with the vehicle make, model, year, socket and adapter.
